# CourseTasksList — задачник

Учебный проект на C# / WPF (.NET 10): настольный планировщик задач.
Приложение собирается пошагово — по одному элементу интерфейса.

## Запуск

Открыть `CourseTasksList.sln` в Visual Studio 2026 и нажать F5, либо из консоли:

```powershell
dotnet run --project CourseTasksList
```

## Текущее состояние

Главное окно:

- заголовок «Задачник» по центру сверху;
- шапка таблицы из четырёх столбцов: «Задача» (в полтора раза шире остальных),
  «Дата добавления» и «Срок сдачи» (вдвое уже), «Статус задачи»;
- четыре пустые строки таблицы: данные в столбцах появятся позже;
- справа у каждой строки кнопки «Р» (станет редактированием) и «✕» (станет удалением),
  обе пока без обработчиков;
- две кнопки внизу: «Добавить задачу» и «Сохранить и выйти» — пока без логики.

## Данные

`CourseTasksList/tasks.json` — файл для хранения задач. Пока пустой список `[]`;
структуру записей и чтение добавим вместе с хранилищем.

## Структура

