# CourseTasksList — задачник

Учебный проект на C# / WPF (.NET 10): настольный планировщик задач.

## Запуск

Открыть `CourseTasksList.sln` в Visual Studio 2026 и нажать F5, либо из консоли:

```powershell
dotnet run --project CourseTasksList
```

## Как работает

Главное окно — таблица задач: «Задача», «Дата добавления», «Срок сдачи», «Статус задачи».
Шапка таблицы закреплена, список прокручивается при большом числе задач.

- **«Добавить задачу»** — в таблице появляется новая строка в режиме ввода:
  можно вписать название и срок сдачи текстом в формате `дд.мм.гггг`
  (можно оставить пустым); дата добавления ставится автоматически
  (сегодняшняя), статус — «Запланировано».
- **«Д»** в строке — подтверждает задачу и добавляет её в планировщик.
  После этого кнопка меняется на **«Р»**.
- **«Р»** — снова открывает строку на редактирование: можно изменить название,
  срок и статус («Запланировано», «В процессе», «Выполнено», «Отложено»).
- **«✕»** — удаляет задачу — и уже добавленную, и ещё не подтверждённую.
- **«Сохранить и выйти»** — записывает задачи в JSON и закрывает программу.
  Строки, которые не подтвердили кнопкой «Д», не сохраняются.

## Данные

Задачи хранятся в JSON рядом с исполняемым файлом
(`bin/Debug/net10.0-windows/tasks.json`). Файл `CourseTasksList/tasks.json`
в проекте — исходный шаблон, он копируется в папку сборки.

> Файлы, сохранённые до появления видов задач, не содержат поля `$type`.
> Такие записи прочитать нельзя — приложение начнёт с пустого списка.

Пример записи (поле `$type` хранит вид задачи — просто́й или со сроком):

```json
{
  "$type": "deadline",
  "Id": "1fdb9ec5-601c-4f74-b956-9eaa9de01c5a",
  "CreatedAt": "2026-10-25T00:00:00",
  "Title": "Сдать курсовую",
  "Deadline": "2026-11-05T00:00:00",
  "Status": "InProgress"
}
```

## Структура

```
CourseTasksList.sln
CourseTasksList/
    App.xaml              ресурсы приложения
    App.xaml.cs           настройка культуры дат (дд.мм.гггг)
    MainWindow.xaml       разметка главного окна и шаблон строки
    MainWindow.xaml.cs    связывание окна с моделью представления
    Models/
        TaskBase.cs       абстрактный базовый класс задачи
        SimpleTask.cs     задача без срока
        DeadlineTask.cs   задача со сроком, умеет считать просрочку
        TaskState.cs      перечисление состояний
        TaskStateExtensions.cs  подписи состояний для интерфейса
        InvalidInputEventArgs.cs  аргументы события об ошибке ввода
    Services/
        ITaskStorage.cs   интерфейс хранилища
        JsonTaskStorage.cs  реализация хранения в JSON
    ViewModels/
        MainViewModel.cs  логика окна: команды, список задач
    Infrastructure/
        ObservableObject.cs  база с INotifyPropertyChanged
        RelayCommand.cs      база команд и две реализации ICommand
```
