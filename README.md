# CourseTasksList — задачник

Учебный проект на C# / WPF (.NET 10): настольный планировщик задач.
Приложение собирается пошагово — по одному элементу интерфейса.

## Запуск

Открыть `CourseTasksList.sln` в Visual Studio 2026 и нажать F5, либо из консоли:

```powershell
dotnet run --project CourseTasksList
```

## Текущее состояние

Главное окно:

- заголовок «Задачник» по центру сверху;
- таблица из четырёх равных столбцов: «Задача», «Дата добавления»,
  «Срок сдачи», «Статус задачи»; справа у каждой строки — крестик
  (пока без обработчика, станет кнопкой удаления);
- три кнопки внизу: «Добавить задачу», «Редактировать задачи»,
  «Сохранить и выйти» — пока без логики.

Строки таблицы сейчас статичные, для проверки разметки.
